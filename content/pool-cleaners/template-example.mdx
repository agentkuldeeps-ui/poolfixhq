## What this page is

This file is a working reference. It is `status: scaffold`, which means it is
`noindex, follow` and excluded from the sitemap, so it can live in the repo
without ever being published.

Every block below is one a real review can use. They are shown in the order a
review should use them, because the order is part of the argument: conclusion
first, reasoning second.

## Performance against the category criteria

A real review works through the criteria published on the category hub, in
order, one heading each. Every product in a category is judged on that same
list, which is what makes the scores comparable rather than decorative.

<TechNote>
  **The tech note is the differentiator.** Every competing review of a product
  says roughly the same things. This block is where the page says the thing the
  others do not know: why a part actually fails, what a specification means in
  practice, or the compatibility trap that costs people money.

  It has to be mechanistic rather than an opinion. "We liked the handle" is not
  a tech note. "The impeller is press-fit, so a jam usually means a new wet end
  rather than a cleanout" is.

  The build enforces one per page and rejects a `techNote` slug that another
  live page already used — if it has been said here before, it is not uncommon
  any more.
</TechNote>
